# Projects

Each **git repository** gets a folder: `projects/<slug>/`.

Slug = git root folder name by default (see `_meta/projects-index.md` for overrides).

Per-repo pack:

- `README.md` — what this repo is
- `decisions.md` — decisions for **this repo only**
- `tools.md` — SaaS/tools used in this repo
- `gotchas.md` — optional

Do not put cross-repo rules here. If unsure global vs this repo, **ask**.
