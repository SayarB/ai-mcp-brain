# Workflows

Multi-step playbooks (ordered prompts) for jobs like shipping a PR or bisecting a bug.

- Global: `workflows/global/<id>.md`
- Per git repo: `projects/<slug>/workflows/<id>.md`
- Registry: [[_index]]

Agents: `resolve_guidance` with `workflow_id` or intent. Prefer existing playbooks over inventing new process.
